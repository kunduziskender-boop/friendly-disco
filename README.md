# friendly-disco — CRM для адвоката

Веб-приложение для учёта **клиентов**, **дел** и **встреч** в одной адвокатской практике. Это демо-версия: данные сохраняются в `localStorage` браузера (без сервера и базы).

Репозиторий на GitHub: `kunduziskender-boop/friendly-disco` (в сообщении указано «friendly-dicso» — имя репозитория: **friendly-disco**).

## Запуск

```bash
npm install
npm run dev
```

Сборка для продакшена:

```bash
npm run build
npm run preview
```

## Возможности

- **Обзор**: счётчики и ближайшие встречи
- **Клиенты**: ФИО, контакты, заметки
- **Дела**: привязка к клиенту, статус, суд/орган, срок, краткое описание
- **Встречи**: дата/время, место, клиент

Для боевого использования понадобятся бэкенд, аутентификация и хранение в БД с учётом требований к защите персональных данных.
